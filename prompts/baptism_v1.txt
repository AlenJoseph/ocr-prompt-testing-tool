## EXTRACTION RULES

### 1. Output Format
- Return **ONLY valid JSON** with no explanations, preamble, or markdown code blocks
- Use the exact schema structure shown above

### 2. Date Handling
- Format: **DD-MM-YYYY** (e.g., "23-06-2021")
- Convert written dates: "Twenty Third June 2021" → "23-06-2021"
- **Validation:** Baptism date must be equal to or after birth date. If dates seem inverted or illogical, leave the suspicious date as empty string ""

### 3. Names and Spelling
- Preserve exact spellings from the document, including:
  - Malayalam/Anglicized variations (e.g., "Cheenkallel", "Alozy", "Thankamma")
  - All initials and abbreviations (e.g., "S.K.N", "T.K.", "O.F.M. Cap", "Jyyadurai")
  - Patronymic suffixes and unusual spellings
- Use Title Case for names (e.g., "Francis Cherian", not "FRANCIS CHERIAN")

### 4. Location Names
- Keep Kerala place names as written in the document
- **parents_residence:** Extract from "parishioners of [place]" or residence mentioned in text
- **place_of_birth:** Extract from "born at [place]" (this can be a hospital, town, or village name)
- Common place names: Vandiperiyar, Anakuzhy, Kottayam, Idukki, Mundakayam, Thopramkudy, etc.
- If birth place or residence is unclear but context suggests Kerala, you may infer nearby places from Kottayam/Idukki districts
- If completely illegible, use empty string ""

### 5. Sponsors
- Extract as array of strings with sponsor names: `["Sponsor 1 Name", "Sponsor 2 Name"]`
- Keep full names with all initials (e.g., "N. Manikandan", "Upakara Mary")
- Typical format: 2 sponsors, but handle 1 or more as found in document
- **sponsors_parish:** Single string field for the parish/parishes of sponsors
  - **FIRST CHECK THE SEAL/STAMP** at lower left for official parish name format
  - If all sponsors are from the baptism parish: use the exact format from the seal
  - If sponsors are from different parishes: combine with " and " (e.g., "Assumption Church, Vandiperiyar and St. Mary's Church, Kottayam")
  - If parish not mentioned or illegible: use empty string ""

### 6. Priest Names
- **baptized_by:** The priest/deacon who performed the baptism ceremony (may say "Baptized by:" in document)
- **parish_priest:** The parish priest at the time (may say "Parish Priest:" or appear at bottom of document)
- These can be the same person or different people
- Use priest timeline to infer incomplete names when baptism year is clear
- Preserve titles exactly: "Fr.", "Deacon", "Decon", "Rev.", etc. (keep even if misspelled in document)
- Keep full names with all abbreviations (e.g., "Fr. Ahib O.F.M. Cap", "Fr. Francis Nedumparambil")

### 7. Parish Names - ALWAYS CHECK THE SEAL/STAMP
- **CRITICAL STEP:** Look for the official church seal/stamp at the **lower left** of the document
- The seal contains the official parish name - use this as the authoritative source
- **baptism_conducted_parish:** 
  - Extract from the seal first
  - Typical format: "Assumption Church, Vandiperiyar" or "Assumption Church, V.P.R. (Vandiperiyar)"
  - If seal is illegible, use church name from the main text
- **sponsors_parish:** Where sponsor(s) are from
  - If same as baptism parish, use the exact same format from seal
  - If different, use their respective parish names
- **parents_residence:** The parish where the parents reside
  - Use same standardization rules as other parish fields

**STANDARDIZATION RULE - CRITICAL:**
For Assumption Church in Vandiperiyar, you may encounter ANY of these variations:
- "V.P.R.", "V.PR", "VPR"
- "Vandiperr", "Vandiperiyar"
- "Assumption Church V.P.R."
- "Assumption", "Assumption Church"
- "Assumption Vandiperiyar"

→ **ALWAYS OUTPUT AS:** "Assumption Church, Vandiperiyar"

This applies to ALL parish fields: baptism_conducted_parish, sponsors_parish, and parents_residence

- Common abbreviations you might see:
  - "V.P.R." = Vandiperiyar
  - "T.U.N." = Thopramkudy
  - Prefer full format: "[Church Name], [Location]"

### 8. Illegible or Missing Data
- If text is illegible, smudged, torn, partially visible, or you cannot confidently read it: use empty string ""
- Do NOT guess or invent information
- Do NOT use "null" - use empty string "" for missing fields
- Do NOT use placeholder text like "unclear" or "unknown"
